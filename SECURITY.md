# Security

Report a suspected vulnerability privately to **security@halveth.de**. Include the affected version or commit, the smallest reproducible sequence, observed result, and impact. Do not include a seed phrase, private key, session token or another person's wallet data.

This repository is a browser portal. Passive local review and tests against self-controlled accounts are appropriate. Do not probe third-party RPCs, wallets, accounts or services beyond their published terms and your authorization. A bug report is not permission to access funds or data.

For a real transaction, verify the destination, chain, value, fee and wallet confirmation independently. The site's successful build is not a security certification or a Mainnet execution receipt.
